# 【原创】TerminalS —— 给飞牛做的 Web 终端：刷新不掉线，关掉窗口进程还在

在飞牛上跑一些需要长时间执行的任务时，最难受的是**刷新一下页面，正在跑的东西就没了**。装依赖、编译、跑脚本，只要页面一断，就得从头再来一遍。

所以写了 TerminalS：一个跑在飞牛上的 Web 终端工作区，目标是把本地终端的使用习惯搬到浏览器里——多标签、随便分屏，而且**关掉浏览器、换个设备打开，接回的还是同一批进程**。

**项目地址：https://github.com/SerenaderZ/terminals**

安装包在 Releases 里，x86 和 arm 都有。

---

## 它解决什么问题

### 刷新、关窗口、换设备，进程都还在

会话跑在服务端，浏览器只是个显示器。刷新页面、关掉标签、手机换成电脑打开，接回来的是同一个 shell，历史输出也在，不用重新 `cd` 一遍再敲命令。

### 关掉界面，任务继续跑

有些命令要跑很久，界面开着占地方。按住 `Shift` 点窗格右侧的 `×`，窗格从界面移走，进程继续在后台跑。标题栏的后台会话入口里能看到还活着的会话，随时接回或结束。

「结束全部」也给了选项：可以只收界面、把进程留在后台，也可以彻底结束。

### 能正常跑全屏程序

vim、htop、Claude Code 这类全屏 TUI，在 Web 终端里最容易出的问题是重连后花屏、退出后留残影。这里做了备用屏幕追踪和尺寸对账，重连后画面能重建；真出残影按 `Ctrl+Alt+K` 清一下就好。

### 分屏是真的分屏

横竖都能分，还能继续嵌套，拖分隔条调比例。关掉一个窗格，空出来的分割会自动折叠，不会留下一条缝。

### 连不上时能看出为什么

右上角的连接状态是个按钮。断开时鼠标移上去会显示三件事：断开的原因（是服务没响应、服务端在重启，还是网关掐断了）、服务本身还活着没、下次自动重连还有几秒。点一下立刻重连，不用干等。

## 安装

1. 到 [Releases](https://github.com/SerenaderZ/terminals/releases) 下载对应架构的包
2. **应用中心 → 设置 → 手动安装**，选 `.fpk`
3. 装完从桌面打开，入口是 `/app/terminals`

系统要求 1.1.3100 及以上。

| 文件 | 适用机器 |
|---|---|
| `terminals_x.y.z_x86.fpk` | Intel / AMD：N100、N305、J4125 等绝大多数机器 |
| `terminals_x.y.z_arm.fpk` | ARM：RK3588 一类开发板 |

服务通过 unix socket 交给飞牛网关转发，**不占用任何 TCP 端口**，也不需要在路由器上额外开端口。

## 常用快捷键

快捷键全部走 `Ctrl+Alt`，因为 `Ctrl+Shift+T/W` 被浏览器强占了，抢不过。

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+T` / `W` | 新建标签 / 关闭当前窗格 |
| `Ctrl+Alt+=` / `-` | 向右 / 向下分屏 |
| `Ctrl+Alt+方向键` | 按方向移动焦点 |
| `Ctrl+Alt+[` `]` / `1..9` | 切换标签 |
| `Ctrl+Alt+K` | 清屏（连历史一起清） |
| `Ctrl+Alt+Q` | 结束全部会话 |
| `Ctrl+Alt+,` | 打开设置 |
| `Shift+Enter` | 换行不提交（Claude Code 里很有用） |

鼠标：`Shift` + 点窗格右侧的 `×` = 移出界面但保留进程；点右上角状态灯 = 立刻重连。

## 关于安全

- 默认**降权到普通账户**运行，不写任何 sudoers 文件。需要 root 的时候自己在终端里 `sudo -i`，密码交互照旧。
- 建议通过飞牛的远程访问（HTTPS）用，局域网 http 直连也能用，只是浏览器在非 HTTPS 页面下不允许网页读系统剪贴板，粘别处复制的内容要用 `Ctrl+V`。

## 已知限制

说在前面，免得踩坑：

- 默认后端下，**应用重启或 NAS 重启会丢会话**。要扛重启可以加 `--backend tmux` 参数，会话跑在 tmux 里，应用升级后能原地认领。
- 输出流控目前是「队列满就丢帧」，网络特别差时可能丢一点输出。
- 布局是整个工作区一份，不是每个用户一份，两个管理员同时在改会互相覆盖。
- WebGL 渲染只给前 4 个窗格，其余走 canvas（浏览器有上下文数量上限）。

## 一些说明

- 后端是 Go，前端 xterm.js，**前端资源全部内嵌在二进制里**，部署时只有一个文件，不用担心静态资源路径。
- 设置（主题、字号、光标闪烁、回看行数、选中即复制）存在服务端，换设备打开还是同一套。
