终端行为
复制与粘贴 拖选文字不会自动复制：想复制就在终端里右键，选中的那段会进剪贴板；没有选区时右键是粘贴。整套只用鼠标，不必按键盘。 这样拖错了、左键点一下取消，什么都不会被复制。 复制时每行末尾那些看不见的填充空白会被去掉（否则粘到会折行的地方会多出空行），换行和空行都原样保留； 框住几行就复制几行，拖到下面的空行也算。 选一块纯空白也能复制，粘出去就是换行（和 Windows 终端一样）。 程序自己要复制（Claude Code、tmux 这类发的 OSC 52）也会真的写进剪贴板。 真要连行尾空白一起带走（对齐的定宽文本），按 Ctrl+Shift+Insert。
把程序留在后台 按住 Shift 点窗格右侧的 ×，窗格会从界面上移走，里面正在跑的程序（比如服务器、构建、Claude Code）继续运行。 右上角的后台会话按钮可以看有哪些在后台，也可以随时接回来。
